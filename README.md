# E-Commerce SQA Automation Project

A portfolio-ready Software Quality Assurance project covering manual testing, API testing, UI automation, regression testing, and CI.

## Project Scope
- Functional, smoke, regression and negative testing
- Test case design and execution tracking
- Defect reporting with severity/priority
- REST API testing with Postman
- UI automation with Python, Selenium and PyTest
- Page Object Model structure
- GitHub Actions CI

## Test Modules
1. Authentication
2. Product search and filtering
3. Product details
4. Shopping cart
5. Checkout and order flow
6. API validation

## Tools
Python | PyTest | Selenium | Postman | Jira-style defect tracking | GitHub Actions
